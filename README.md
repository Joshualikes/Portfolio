# Antonio Portfolio

A modern, dark-themed developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion — matching the provided design reference.

## Features

- Sticky navbar with active section highlighting
- Hero section with animated VS Code editor mockup
- About section with feature cards
- Skills grid with technology icons
- Featured projects showcase
- Contact CTA with gradient banner
- Responsive footer with back-to-top

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Customize Your Portfolio

Edit `src/data/portfolioData.js` to update:

- Your name, title, and bio
- Contact info and social links
- Skills and projects
- Footer services

Replace the profile photo in `src/components/About.jsx` and add your resume PDF link in `portfolioData.js`.

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Framer Motion
- React Icons
